How to use ⌁ 3 steps

STEP 1 — COPY

Hover any specimen card and hit its yellow COPY button. The exact HTML of that button lands in your clipboard.

STEP 2 — PASTE

Drop it straight into your markup. Every button is a real <button> element with two classes: bn + a variant class.

STEP 3 — CSS ONCE

Hit COPY FULL CSS in the header and save it as buttonarium.css. Link it once — all 122 buttons work forever.

⚠ Keep the base .bn class on every button — it carries the shared reset. Everything else is pure CSS. Works inside forms, navbars, cards, anywhere.
